# 📘 Software Design Document (SDD)
## Project: **Digital Marketplace Platform** (Python/Django)

### 1. Introduction
**Purpose:** Buyers aur Sellers ko connect karne wala digital marketplace — jahan sellers digital products (templates, UI kits, graphics, courses) bech sakte hain aur buyers unhe kharid sakte hain.

**Scope:** Web app (responsive), user auth, product listing, cart, checkout (mock/dummy payment), seller dashboard.

### 2. Target Users
| User | Role |
|------|------|
| **Buyer** | Browse, search, cart, buy, download |
| **Seller** | Product upload, manage listings, view sales |
| **Admin** | Approve products, manage users, reports |

### 3. Functional Requirements
- **Auth:** Register/Login (Buyer/Seller role), profile
- **Browse:** Homepage featured products, categories, search, filters (price, category, rating)
- **Product Page:** Images, description, price, reviews, "Add to Cart"
- **Cart & Checkout:** Quantity, total, dummy payment gateway
- **Seller Dashboard:** Add/Edit/Delete product, sales history
- **Admin Panel:** Approve/reject products, user management
- **Reviews & Ratings**
- **Download link** after purchase (secure, token-based)

### 4. Non-Functional Requirements
- Responsive (mobile + desktop)
- Dark theme UI (image jaisa)
- Fast load (<2s)
- Secure auth (CSRF, password hashing)
- Scalable DB

### 5. Tech Stack
- **Backend:** Python 3.10+ , **Django 4.x**
- **Frontend:** Django Templates + Bootstrap 5 (dark theme) / Tailwind
- **Database:** SQLite (dev) → PostgreSQL (prod)
- **Auth:** Django built-in `django.contrib.auth`
- **Images:** Pillow
- **Deployment:** Render / Railway

### 6. Database Design (Models)
```
User (built-in) — role: buyer/seller
Category(id, name, slug)
Product(id, seller_id, category_id, title, slug, description, price, image, file, status, created_at)
Cart(id, user_id, product_id, qty)
Order(id, user_id, total, status, created_at)
OrderItem(id, order_id, product_id, price)
Review(id, product_id, user_id, rating, comment)
```

### 7. URL/API Design
| URL | View |
|-----|------|
| `/` | Homepage (featured) |
| `/products/` | Product list + filters |
| `/product/<slug>/` | Product detail |
| `/cart/` | Cart page |
| `/checkout/` | Checkout |
| `/seller/dashboard/` | Seller panel |
| `/seller/product/add/` | Add product |
| `/admin/` | Django admin |

### 8. User Flow
`Home → Browse/Search → Product → Add to Cart → Login → Checkout → Order Success → Download`

### 9. UI/UX
- Dark background (#1a1a2e), orange accent (#ff6b35) — image jaisa
- Top navbar: Logo, Categories, Search, Cart, Profile
- Product cards with image, title, price, rating
- Sidebar filters on listing page

### 10. Deployment
- `requirements.txt`, `.env` for secrets
- Render/Railway pe deploy
- `collectstatic` + WhiteNoise for static files

## 🟡 Level 2 — Detailed DFD (har process ka breakdown)

### **Process 1.0 — Authentication**
```
Buyer/Seller ──(email, password, role)──▶ [1.1 Register]
                                              │
                                              ▼
                                         [User DB]
Buyer/Seller ──(email, password)────────▶ [1.2 Login]
                                              │
                                              ▼
                                         Session token ──▶ Browser
```

### **Process 2.0 — Browse & Search**
```
Buyer ──(search keyword, category)──▶ [2.1 Search Filter]
                                            │
                                            ▼
                                      [Product DB] ──▶ filtered list ──▶ Buyer
Buyer ──(product id)──▶ [2.2 Product Detail Fetch] ──▶ Product details + Reviews
```

### **Process 3.0 — Cart**
```
Buyer ──(add/remove/qty)──▶ [3.1 Cart Update] ──▶ [Cart DB]
Buyer ──(view cart)──▶ [3.2 Cart Display] ──▶ Cart DB ──▶ items + total
```

### **Process 4.0 — Checkout**
```
Buyer ──(place order)──▶ [4.1 Order Create] ──▶ [Order DB]
Buyer ──(dummy pay)──▶ [4.2 Payment Simulate] ──▶ status = PAID
                              │
                              ▼
                        [Order DB] ──▶ Receipt / Email ──▶ Buyer
```

### **Process 5.0 — Download & Review**
```
Buyer ──(download req)──▶ [5.1 Verify Purchase] ──▶ Order DB
                              │ verified
                              ▼
                        [5.2 Generate Token] ──▶ secure download link ──▶ Buyer
Buyer ──(rating, comment)──▶ [5.3 Save Review] ──▶ Review DB
```

### **Process 6.0 — Seller Management**
```
Seller ──(product data + file)──▶ [6.1 Add Product] ──▶ Product DB (status=pending)
Seller ──(edit/delete)──▶ [6.2 Update Product] ──▶ Product DB
Seller ──(view sales)──▶ [6.3 Sales Report] ──▶ Order DB ──▶ report
```

### **Process 7.0 — Admin**
```
Admin ──(approve/reject)──▶ [7.1 Product Approval] ──▶ Product DB (status=approved)
Admin ──(block/unblock)──▶ [7.2 User Management] ──▶ User DB
Admin ──(view reports)──▶ [7.3 Reports] ──▶ Order DB + Product DB
```

## 6️⃣ Django Model Code (Bonus — Ready to Paste)

```python
# accounts/models.py
from django.db import models
from django.contrib.auth.models import AbstractUser

class User(AbstractUser):
    ROLE_CHOICES = (('buyer','Buyer'),('seller','Seller'),('admin','Admin'))
    role = models.CharField(max_length=10, choices=ROLE_CHOICES, default='buyer')
    phone = models.CharField(max_length=15, blank=True)
    avatar = models.ImageField(upload_to='avatars/', blank=True, null=True)

# marketplace/models.py
class Category(models.Model):
    name = models.CharField(max_length=100)
    slug = models.SlugField(unique=True)
    description = models.TextField(blank=True)
    image = models.ImageField(upload_to='categories/', blank=True)

class Product(models.Model):
    STATUS = (('pending','Pending'),('approved','Approved'),('rejected','Rejected'))
    seller = models.ForeignKey(User, on_delete=models.CASCADE, related_name='products')
    category = models.ForeignKey(Category, on_delete=models.SET_NULL, null=True)
    title = models.CharField(max_length=200)
    slug = models.SlugField(unique=True)
    description = models.TextField()
    price = models.DecimalField(max_digits=10, decimal_places=2)
    image = models.ImageField(upload_to='products/')
    file = models.FileField(upload_to='files/')
    status = models.CharField(max_length=10, choices=STATUS, default='pending')
    created_at = models.DateTimeField(auto_now_add=True)

class Review(models.Model):
    product = models.ForeignKey(Product, on_delete=models.CASCADE, related_name='reviews')
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    rating = models.IntegerField(default=5)
    comment = models.TextField(blank=True)
    created_at = models.DateTimeField(auto_now_add=True)

# orders/models.py
class CartItem(models.Model):
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    product = models.ForeignKey(Product, on_delete=models.CASCADE)
    quantity = models.IntegerField(default=1)
    added_at = models.DateTimeField(auto_now_add=True)

class Order(models.Model):
    STATUS = (('pending','Pending'),('paid','Paid'),('failed','Failed'))
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    total = models.DecimalField(max_digits=10, decimal_places=2)
    status = models.CharField(max_length=10, choices=STATUS, default='pending')
    created_at = models.DateTimeField(auto_now_add=True)

class OrderItem(models.Model):
    order = models.ForeignKey(Order, on_delete=models.CASCADE, related_name='items')
    product = models.ForeignKey(Product, on_delete=models.CASCADE)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    quantity = models.IntegerField(default=1)

class Download(models.Model):
    order = models.ForeignKey(Order, on_delete=models.CASCADE)
```

## 7️⃣ Add to Cart — Fly-to-Cart Animation 🛒

**Kya hoga:** Click karte hi product image ek chhota flying circle ban ke cart icon tak jayega.

```js
function flyToCart(imgEl, cartIcon) {
  const clone = imgEl.cloneNode();
  const rect = imgEl.getBoundingClientRect();
  const cartRect = cartIcon.getBoundingClientRect();
  
  clone.style.cssText = `
    position: fixed;
    left: ${rect.left}px;
    top: ${rect.top}px;
    width: 60px; height: 60px;
    border-radius: 50%;
    z-index: 9999;
    transition: all 0.8s cubic-bezier(0.5, -0.5, 1, 1);
    pointer-events: none;
  `;
  document.body.appendChild(clone);
  
  requestAnimationFrame(() => {
    clone.style.left = cartRect.left + 'px';
    clone.style.top = cartRect.top + 'px';
    clone.style.transform = 'scale(0.2)';
    clone.style.opacity = '0';
  });
  
  setTimeout(() => clone.remove(), 850);
  cartIcon.classList.add('bounce');
  setTimeout(() => cartIcon.classList.remove('bounce'), 400);
}
```

```js
let dots = Array.from({length: 50}, () => ({

  y: Math.random()*innerHeight,
  r: Math.random()*2+1,
  vx: (Math.random()-0.5)*0.5,
  vy: (Math.random()-0.5)*0.5,
  a: Math.random()*0.5+0.2
}));
function draw() {
  ctx.clearRect(0,0,innerWidth,innerHeight);
  dots.forEach(d => {
    d.x += d.vx; d.y += d.vy;
    if (d.x<0||d.x>innerWidth) d.vx*=-1;
    if (d.y<0||d.y>innerHeight) d.vy*=-1;
    ctx.beginPath();
    ctx.arc(d.x, d.y, d.r, 0, Math.PI*2);
    ctx.fillStyle = `rgba(255,107,53,${d.a})`;
    ctx.fill();
  });
  requestAnimationFrame(draw);
}
draw();
```

```javascript
// ===== NAVBAR SCROLL =====
const navbar = document.getElementById('navbar');
window.addEventListener('scroll', () => {
    navbar.classList.toggle('scrolled', window.scrollY > 50);

// ===== PROFILE DROPDOWN (mobile toggle) =====
const profileBtn = document.getElementById('profileBtn');
if (profileBtn) {
    profileBtn.addEventListener('click', (e) => {
        e.stopPropagation();
        document.getElementById('profileDropdown').classList.toggle('open');
    });
}

// ===== TOAST NOTIFICATION =====
function showToast(message, type = 'info') {
    const container = document.getElementById('toastContainer');
    const toast = document.createElement('div');
    toast.className = `toast ${type}`;
    toast.textContent = message;
    container.appendChild(toast);
    setTimeout(() => {
        toast.classList.add('hide');
        setTimeout(() => toast.remove(), 300);
    }, 3000);
}

// ===== ADD TO CART + FLY ANIMATION =====
function addToCart(productId, imageEl) {
    const cartIcon = document.getElementById('cartIcon');
    
    if (imageEl) {
        const clone = imageEl.cloneNode();
        const rect = imageEl.getBoundingClientRect();
        const cartRect = cartIcon.getBoundingClientRect();
        
        clone.style.cssText = `
            position: fixed;
            left: ${rect.left}px;
            top: ${rect.top}px;
            width: 60px; height: 60px;
            border-radius: 50%;
            z-index: 9999;
            transition: all 0.8s cubic-bezier(0.5, -0.5, 1, 1);
            pointer-events: none;
            object-fit: cover;
        `;
        document.body.appendChild(clone);
        
        requestAnimationFrame(() => {
            clone.style.left = cartRect.left + 'px';
            clone.style.top = cartRect.top + 'px';
            clone.style.transform = 'scale(0.2)';
            clone.style.opacity = '0';
        });
        
        setTimeout(() => clone.remove(), 850);
    }
    
    cartIcon.classList.add('bounce');
    setTimeout(() => cartIcon.classList.remove('bounce'), 400);
    
    // Update badge
    const badge = document.getElementById('cartBadge');
    badge.textContent = parseInt(badge.textContent) + 1;
    
    showToast('✅ Added to cart!', 'success');
}

// ===== LIVE SEARCH =====
const searchInput = document.getElementById('searchInput');
const searchResults = document.getElementById('searchResults');
let searchTimer;

if (searchInput) {
    searchInput.addEventListener('input', (e) => {
        clearTimeout(searchTimer);
        const q = e.target.value.trim();
        
        if (q.length < 2) {
            searchResults.classList.remove('open');
            return;
        }
        
        searchTimer = setTimeout(() => {
            // Replace with real fetch to /api/search/?q=
            searchResults.innerHTML = `
                <a href="/product/knight-ui/">📦 Knight UI Kit</a>
                <a href="/product/arena-graphic/">📦 Arena Graphic Pack</a>
                <a href="/search/?q=${encodeURIComponent(q)}">🔍 See all results for "${q}"</a>
            `;
            searchResults.classList.add('open');
        }, 300);
    });
    
    document.addEventListener('click', (e) => {
        if (!searchInput.contains(e.target) && !searchResults.contains(e.target)) {
            searchResults.classList.remove('open');
        }
    });
}

// ===== SCROLL REVEAL =====
const observer = new IntersectionObserver((entries) => {
    entries.forEach(e => {
        if (e.isIntersecting) {
            e.target.classList.add('visible');
            observer.unobserve(e.target);
        }
    });
}, { threshold: 0.15 });

document.querySelectorAll('.reveal').forEach(el => observer.observe(el));

// ===== NEWSLETTER =====
document.querySelectorAll('.newsletter-form').forEach(form => {
    form.addEventListener('submit', (e) => {
        e.preventDefault();
        showToast('📧 Subscribed! Check your email.', 'success');
        form.reset();
    });
});
```

# 📘 SDD — Single-File Marketplace App (`app.py`)

## 1. Introduction
**Purpose:** Ek complete Digital Marketplace jisme buyers, sellers, aur admin — sab ek hi Python file (`app.py`) se chalayein. SDD ke saare features (DFD, ER, Use Case, Class Diagram) implement honge.

**Scope:** Single-file Flask app with inline templates, SQLite DB, dummy payment, animations.

## 2. Architecture
```
┌─────────────────────────────────────────────┐
│              app.py (Single File)           │
│  ┌────────────────────────────────────────┐ │
│  │  Flask App + Routes (25+ endpoints)    │ │
│  ├────────────────────────────────────────┤ │
│  │  SQLAlchemy Models (8 tables)          │ │
│  │  User, Category, Product, CartItem,    │ │
│  │  Order, OrderItem, Review, Download    │ │
│  ├────────────────────────────────────────┤ │
│  │  Inline HTML Templates (Jinja)         │ │
│  │  base, home, products, detail, cart... │ │
│  ├────────────────────────────────────────┤ │
│  │  Static CSS + JS (inline strings)      │ │
│  └────────────────────────────────────────┘ │
└─────────────────┬───────────────────────────┘
                  │
                  ▼
          ┌──────────────┐
          │ SQLite DB    │
          │ (market.db)  │
          └──────────────┘
```

## 3. Tech Stack
| Layer | Tech |
|-------|------|
| Backend | Python 3.10+, Flask 3.x |
| ORM | Flask-SQLAlchemy |
| Auth | Flask-Login |
| DB | SQLite (`market.db`) |
| Frontend | Inline Jinja2 templates |
| CSS/JS | Inline strings (dark theme) |
| Uploads | Local `uploads/` folder |

## 4. Pages Included (25+)
Home, Products, Product Detail, Search, Category, Cart, Checkout, Order Success, My Orders, My Downloads, My Reviews, Profile, Seller Dashboard, Add Product, My Products, Sales, Earnings, Admin Dashboard, Approvals, Manage Users, Manage Categories, Reports, Login, Register, Logout, About, Contact, 404.

## 5. Modules (all in app.py)
| Module | Lines | Purpose |
|--------|-------|---------|
| Config | 1–30 | Flask setup |
| Models | 30–150 | 8 SQLAlchemy classes |
| Auth | 150–250 | Login/Register/Logout |
| Public Routes | 250–400 | Home, Products, Detail, Search |
| Cart & Checkout | 400–550 | Cart, Checkout, Payment |
| Seller Routes | 550–700 | Seller dashboard, Add product |
| Admin Routes | 700–800 | Approvals, Users, Categories |
| Templates | 800–2000 | All inline HTML |
| Run | Last line | `app.run()` |

## 6. Database (Same as ER Diagram)
`User, Category, Product, CartItem, Order, OrderItem, Review, Download` — same fields.

## 7. Security
- Password hashing (`werkzeug.security`)
- Login required decorators
- CSRF (Flask-WTF optional)
- Role-based access (buyer/seller/admin)
- Secure download tokens

```python
"""
=============================================================
DIGITAL MARKETPLACE — Single-File Flask App
=============================================================
Run:
    pip install flask flask-sqlalchemy flask-login
    python app.py

Visit: http://127.0.0.1:5000
=============================================================
"""

from flask import Flask, render_template_string, request, redirect, url_for, flash, session, send_from_directory, abort
from flask_sqlalchemy import SQLAlchemy
from flask_login import LoginManager, UserMixin, login_user, logout_user, login_required, current_user
from werkzeug.security import generate_password_hash, check_password_hash
from werkzeug.utils import secure_filename
from datetime import datetime
import os, uuid, random

# ============================================================
# CONFIG
# ============================================================
app = Flask(__name__)
app.config['SECRET_KEY'] = 'change-this-in-production-xyz123'
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///market.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False
app.config['UPLOAD_FOLDER'] = 'uploads'
app.config['MAX_CONTENT_LENGTH'] = 50 * 1024 * 1024  # 50MB

os.makedirs(app.config['UPLOAD_FOLDER'], exist_ok=True)

db = SQLAlchemy(app)
login_manager = LoginManager(app)
login_manager.login_view = 'login'

# ============================================================
# MODELS
# ============================================================
class User(UserMixin, db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    password = db.Column(db.String(200), nullable=False)
    role = db.Column(db.String(20), default='buyer')  # buyer/seller/admin
    phone = db.Column(db.String(20), default='')
    avatar = db.Column(db.String(200), default='')
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

class Category(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    slug = db.Column(db.String(100), unique=True)
    description = db.Column(db.Text, default='')
    image = db.Column(db.String(200), default='')

class Product(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    seller_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    category_id = db.Column(db.Integer, db.ForeignKey('category.id'))
    title = db.Column(db.String(200), nullable=False)
    slug = db.Column(db.String(200), unique=True)
    description = db.Column(db.Text, default='')
    price = db.Column(db.Float, default=0.0)
    image = db.Column(db.String(200), default='')
    file = db.Column(db.String(200), default='')
    status = db.Column(db.String(20), default='pending')  # pending/approved/rejected
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    seller = db.relationship('User', backref='products')
    category = db.relationship('Category', backref='products')

    def avg_rating(self):
        reviews = Review.query.filter_by(product_id=self.id).all()
        if not reviews: return 4.8
        return round(sum(r.rating for r in reviews) / len(reviews), 1)

class CartItem(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    product_id = db.Column(db.Integer, db.ForeignKey('product.id'), nullable=False)
    quantity = db.Column(db.Integer, default=1)
    added_at = db.Column(db.DateTime, default=datetime.utcnow)
    product = db.relationship('Product')

class Order(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    total = db.Column(db.Float, default=0.0)
    status = db.Column(db.String(20), default='pending')
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    items = db.relationship('OrderItem', backref='order', cascade='all, delete-orphan')

class OrderItem(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    order_id = db.Column(db.Integer, db.ForeignKey('order.id'), nullable=False)
    product_id = db.Column(db.Integer, db.ForeignKey('product.id'), nullable=False)
    price = db.Column(db.Float)
    quantity = db.Column(db.Integer, default=1)
    product = db.relationship('Product')

class Review(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    product_id = db.Column(db.Integer, db.ForeignKey('product.id'), nullable=False)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    rating = db.Column(db.Integer, default=5)
    comment = db.Column(db.Text, default='')
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    user = db.relationship('User')

class Download(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    order_id = db.Column(db.Integer, db.ForeignKey('order.id'), nullable=False)
    product_id = db.Column(db.Integer, db.ForeignKey('product.id'), nullable=False)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    token = db.Column(db.String(64), unique=True)
    downloaded = db.Column(db.Boolean, default=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    product = db.relationship('Product')

@login_manager.user_loader
def load_user(user_id):
    return User.query.get(int(user_id))

@app.route('/checkout/', methods=['GET', 'POST'])
@login_required
def checkout():
    items = CartItem.query.filter_by(user_id=current_user.id).all()
    if not items:
        flash('Cart is empty', 'error'); return redirect(url_for('cart'))
    subtotal = sum(i.product.price * i.quantity for i in items)
    total = subtotal * 1.1
    if request.method == 'POST':
        order = Order(user_id=current_user.id, total=total, status='paid')
        db.session.add(order); db.session.flush()
        for i in items:
            db.session.add(OrderItem(order_id=order.id, product_id=i.product_id,
                                     price=i.product.price, quantity=i.quantity))
            db.session.add(Download(order_id=order.id, product_id=i.product_id,
                                    user_id=current_user.id, token=str(uuid.uuid4())))
        CartItem.query.filter_by(user_id=current_user.id).delete()
        db.session.commit()
        return redirect(url_for('order_success', oid=order.id))
    return render_template_string(CHECKOUT_HTML, total=total)
```

```javascript
/* ============ 3. BUTTON RIPPLE ============ */
document.addEventListener('click', (e) => {
    const btn = e.target.closest('.btn-primary, .btn-outline');
    if (!btn || prefersReduced) return;
    const r = document.createElement('span');
    r.className = 'ripple';
    const size = Math.max(btn.clientWidth, btn.clientHeight);
    const rect = btn.getBoundingClientRect();
    r.style.width = r.style.height = size + 'px';
    r.style.left = (e.clientX - rect.left - size/2) + 'px';
    r.style.top  = (e.clientY - rect.top  - size/2) + 'px';
    btn.appendChild(r);
    setTimeout(() => r.remove(), 650);
});

/* ============ 4. FLY TO CART ============ */
function flyToCart(sourceEl, cartEl) {
    if (prefersReduced || !sourceEl || !cartEl) return;
    const clone = sourceEl.cloneNode();
    const sRect = sourceEl.getBoundingClientRect();
    const cRect = cartEl.getBoundingClientRect();
    clone.classList.add('flying-img');
    clone.style.left = sRect.left + 'px';
    clone.style.top  = sRect.top + 'px';
    clone.style.width = '60px';
    clone.style.height = '60px';
    document.body.appendChild(clone);
    requestAnimationFrame(() => {
        clone.style.left = (cRect.left + 10) + 'px';
        clone.style.top  = (cRect.top + 10) + 'px';
        clone.style.width = '10px';
        clone.style.height = '10px';
        clone.style.opacity = '0';
    });
    setTimeout(() => {
        clone.remove();
        const cart = document.getElementById('cartIcon');
        const badge = document.getElementById('cartBadge');
        if (cart) { cart.classList.add('bounce'); setTimeout(()=>cart.classList.remove('bounce'), 600); }
        if (badge) { badge.classList.add('pop'); setTimeout(()=>badge.classList.remove('pop'), 600); }
    }, 850);
}

/* ============ 8. HERO PARTICLES ============ */
function initParticles() {
    const canvas = document.getElementById('particleCanvas');
    if (!canvas || prefersReduced) return;
    const ctx = canvas.getContext('2d');
    let W, H, dots;
    const resize = () => {
        W = canvas.width = canvas.offsetWidth;
        H = canvas.height = canvas.offsetHeight;
        dots = Array.from({length: 40}, () => ({
            x: Math.random()*W, y: Math.random()*H,
            r: Math.random()*1.8+0.5,
            vx: (Math.random()-.5)*.3, vy: (Math.random()-.5)*.3,
            a: Math.random()*.5+.2
        }));
    };
    resize();
    window.addEventListener('resize', resize);
    (function draw(){
        ctx.clearRect(0,0,W,H);
        dots.forEach(d => {
            d.x += d.vx; d.y += d.vy;
            if (d.x<0||d.x>W) d.vx*=-1;
            if (d.y<0||d.y>H) d.vy*=-1;
            ctx.beginPath();
            ctx.arc(d.x,d.y,d.r,0,Math.PI*2);
            ctx.fillStyle = `rgba(255,107,53,${d.a})`;
            ctx.fill();
        });
        requestAnimationFrame(draw);
    })();
}
initParticles();

/* ============ 9. CONFETTI ============ */
function blastConfetti() {
    if (prefersReduced) return;
    const canvas = document.createElement('canvas');
    canvas.id = 'confettiCanvas';
    document.body.appendChild(canvas);
    const ctx = canvas.getContext('2d');
    canvas.width = innerWidth; canvas.height = innerHeight;
    const colors = ['#ff6b35','#ff8456','#ffc107','#2ecc71','#9b59ff'];
    const parts = Array.from({length: 120}, () => ({
        x: innerWidth/2 + (Math.random()-.5)*200,
        y: innerHeight/2,
        vx: (Math.random()-.5)*14,
        vy: Math.random()*-16 - 5,
        size: Math.random()*6+4,
        color: colors[Math.floor(Math.random()*colors.length)],
        rot: Math.random()*Math.PI,
        vr: (Math.random()-.5)*.3,
        life: 1
    }));
    let t = 0;
    (function loop(){
        t++;
        ctx.clearRect(0,0,canvas.width,canvas.height);
        parts.forEach(p => {
            p.vy += .45;
            p.x += p.vx; p.y += p.vy; p.rot += p.vr;
            p.life -= .008;
            ctx.save();
            ctx.translate(p.x,p.y); ctx.rotate(p.rot);
            ctx.globalAlpha = Math.max(p.life, 0);
            ctx.fillStyle = p.color;
            ctx.fillRect(-p.size/2,-p.size/2,p.size,p.size*1.6);
            ctx.restore();
        });
        if (t < 220) requestAnimationFrame(loop);
        else canvas.remove();
    })();
}
```

```javascript
/* ============ 1. MAGNETIC CURSOR ============ */
if (!prefersReduced && window.matchMedia('(hover:hover)').matches) {
    document.querySelectorAll('.btn-primary, .btn-outline, .nav-logo').forEach(btn => {
        btn.classList.add('magnetic-btn');
        btn.addEventListener('mousemove', (e) => {
            const r = btn.getBoundingClientRect();
            const x = (e.clientX - r.left - r.width/2) * 0.25;
            const y = (e.clientY - r.top  - r.height/2) * 0.25;
            btn.style.transform = `translate(${x}px, ${y}px)`;
        });
        btn.addEventListener('mouseleave', () => btn.style.transform = '');
    });
}

/* ============ 2. PARALLAX HERO ============ */
const parallaxLayers = document.querySelectorAll('.parallax-layer');
if (parallaxLayers.length && !prefersReduced) {
    window.addEventListener('scroll', () => {
        const y = window.scrollY;
        parallaxLayers.forEach(layer => {
            const speed = parseFloat(layer.dataset.speed || 0.2);
            layer.style.transform = `translateY(${y * speed}px)`;
        });
    });
}

/* ============ 3. TYPEWRITER ============ */
function typewriter(el, text, speed = 60) {
    let i = 0;
    el.textContent = '';
    el.classList.add('typewriter');
    (function type() {
        if (i < text.length) {
            el.textContent += text.charAt(i++);
            setTimeout(type, speed);
        }
    })();
}
document.querySelectorAll('[data-typewriter]').forEach(el => {
    setTimeout(() => typewriter(el, el.dataset.typewriter), 400);
});

/* ============ 4. NUMBER ODOMETER ============ */
function animateNumber(el, target, duration = 1500) {
    const start = performance.now();
    const from = 0;
    (function step(now) {
        const p = Math.min((now - start) / duration, 1);
        const eased = 1 - Math.pow(1 - p, 3);
        const val = Math.floor(from + (target - from) * eased);
        el.textContent = val.toLocaleString('en-IN');
        if (p < 1) requestAnimationFrame(step);
        else el.textContent = target.toLocaleString('en-IN');
    })(start);
}
const odometerObs = new IntersectionObserver((entries) => {
    entries.forEach(e => {
        if (e.isIntersecting) {
            const val = parseInt(e.target.dataset.value || '0');
            animateNumber(e.target, val);
            odometerObs.unobserve(e.target);
        }
    });
}, { threshold: 0.4 });
document.querySelectorAll('.odometer[data-value]').forEach(el => odometerObs.observe(el));

/* ============ 5. CARD SPOTLIGHT ============ */
document.querySelectorAll('.product-card').forEach(card => {
    card.classList.add('spotlight-card');
    card.addEventListener('mousemove', (e) => {
        const r = card.getBoundingClientRect();
        card.style.setProperty('--mx', `${e.clientX - r.left}px`);
        card.style.setProperty('--my', `${e.clientY - r.top}px`);
    });
});

/* ============ 6. IMAGE REVEAL MASK ============ */
const maskObs = new IntersectionObserver((entries) => {
    entries.forEach(e => {
        if (e.isIntersecting) {
            e.target.classList.add('visible');
            maskObs.unobserve(e.target);
        }
    });
}, { threshold: 0.2 });
document.querySelectorAll('.img-wrap').forEach(el => {
    el.classList.add('reveal-mask');
    maskObs.observe(el);
});

/* ============ 7. SCROLL PROGRESS ============ */
const progress = document.createElement('div');
progress.className = 'scroll-progress';
document.body.appendChild(progress);
window.addEventListener('scroll', () => {
    const h = document.documentElement.scrollHeight - window.innerHeight;
    progress.style.width = (window.scrollY / h * 100) + '%';
});

/* ============ 8. TEXT SCRAMBLE ============ */
function scrambleText(el, final, duration = 1200) {
    const chars = '!<>-_\\/[]{}—=+*^?#________';
    let iter = 0;
    const total = Math.floor(duration / 40);
    const old = el.textContent.split('');
    const target = final.split('');
    (function run() {
        el.textContent = target.map((c, i) => {
            if (i < iter * target.length / total) return c;
            return chars[Math.floor(Math.random() * chars.length)];
        }).join('');
        if (iter++ < total) requestAnimationFrame(run);
        else el.textContent = final;
    })();
}
const logo = document.querySelector('.nav-logo');
if (logo && !prefersReduced) {
    logo.addEventListener('mouseenter', () => {
        const span = logo.querySelector('.logo-text') || logo;
        const original = span.textContent.replace('▶','').trim();
        scrambleText(span, original);
    });
}

/* ============ 9. CURSOR TRAIL ============ */
if (!prefersReduced && window.matchMedia('(hover:hover)').matches) {
    let last = 0;
    document.addEventListener('mousemove', (e) => {
        const now = Date.now();
        if (now - last < 50) return;
        last = now;
        const dot = document.createElement('div');
        dot.className = 'cursor-dot';
        dot.style.left = e.clientX + 'px';
        dot.style.top  = e.clientY + 'px';
        document.body.appendChild(dot);
        setTimeout(() => dot.remove(), 800);
    });
}

/* ============ 10. SHAKE ON ERROR ============ */
document.querySelectorAll('input[required]').forEach(inp => {
    inp.addEventListener('invalid', () => {
        inp.classList.add('shake');
        setTimeout(() => inp.classList.remove('shake'), 500);
    });
});

/* ============ 11. FORM ERROR TOAST ============ */
document.querySelectorAll('form').forEach(f => {
    f.addEventListener('submit', (e) => {
        let bad = false;
        f.querySelectorAll('input[required]').forEach(inp => {
            if (!inp.value.trim()) { bad = true; inp.classList.add('shake'); }
        });
        if (bad) {
            e.preventDefault();
            showToast('⚠️ Please fill all required fields', 'error');
            setTimeout(() => f.querySelectorAll('.shake').forEach(el => el.classList.remove('shake')), 500);
        }
    });
});

/* ============ 12. BALLOON POP ON REMOVE ============ */
document.querySelectorAll('a[href*="/cart/remove/"]').forEach(link => {
    link.addEventListener('click', (e) => {
        const row = link.closest('div[style*="display:flex"]') || link.closest('.cart-item');
        if (row) {
            e.preventDefault();
            row.classList.add('popping');
            setTimeout(() => window.location.href = link.href, 400);
        }
    });
});

/* ============ 13. MORPH CART ICON ============ */
document.querySelectorAll('form[action*="/cart/add/"]').forEach(form => {
    form.addEventListener('submit', () => {
        const icon = document.getElementById('cartIcon');
        if (icon) {
            icon.classList.add('morph-icon', 'added');
            setTimeout(() => icon.classList.remove('morph-icon','added'), 1200);
        }
    });
});

/* ============ 14. SMOOTH SCROLL LINKS ============ */
document.querySelectorAll('a[href^="#"]').forEach(a => {
    a.addEventListener('click', (e) => {
        const target = document.querySelector(a.getAttribute('href'));
        if (target) {
            e.preventDefault();
            target.scrollIntoView({ behavior:'smooth', block:'start' });
        }
    });
});
```
